# FM4 Recomp QHD playtest

Double-click **Play QHD Performance.command** to play. On first use the launcher can reuse your existing Disc 1 installation. For a new setup, open **FM4 Recomp.app** and select your own Forza Motorsport 4 USA Disc 1 ISO. The app includes the setup tools. It requires Apple silicon and macOS 26 or later.

During a single-player race press **Start**, select **GRAPHICS**, then press **A**. The same settings open with **⌘,** on a Mac. In the settings panel use **Y** to save and apply changes and **B** to go back. The playtest launcher requests native QHD, Standard edge smoothing and automatic HDR.

This build runs the ShiftGlue engine. Its profile and session logs are under `~/Library/Application Support/FM4 Recomp ShiftGlue Playtest/`. The launcher can point to Disc 1 files stored elsewhere. Saves for this engine are in the profile's `shiftglue/user/` folder.

The game executable contains code translated from the original game. Players supply their own game data. The [FM4 Recomp notices](licenses/THIRD_PARTY_NOTICES.md) and [engine notices](engines/shiftglue/licenses/reference-host-notices.md) accompany the kit.
