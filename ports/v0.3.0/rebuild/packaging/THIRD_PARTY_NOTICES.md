## Replacing an engine decoder
The release source archive includes the matching source and `rebuild/build-libraries.py`. The companion README gives build commands. To use your own compatible build, work on a copy of the app. Copy the three rebuilt runtime dylibs into `Contents/Resources/kit/engines/shiftglue/` and retain their filenames and `@rpath` install names. Individually ad-hoc sign any changed library with `codesign --force --sign - <library>`, then sign and verify the copied app with `codesign --force --sign - "FM4 Recomp.app"` and `codesign --verify --deep --strict "FM4 Recomp.app"`. A modified copy has its own signature.
