# Support and contact

REtronative's temporary public contact address for its projects is
[retronativeorg@gmail.com](mailto:retronativeorg@gmail.com).

For FM4 Recomp usage questions and bug reports, use the repository's
[GitHub issues](https://github.com/retronative/fm4-recomp/issues). Include the version (or the commit you built),
steps to reproduce and the stop line or error message from the log.

Security and community reporting by email is **pending confirmation** of mailbox access,
monitoring and confidential report handling. Until confirmed, use [SECURITY.md](SECURITY.md)
for vulnerabilities and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct reports.
Do not send sensitive reports to the general contact address while confirmation is pending.

Never include game files, disc images, executables, recompiled code or a built binary in
messages or reports. Describe the relevant files by name and version instead.
